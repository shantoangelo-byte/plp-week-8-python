# Personal Mini-Toolkit

## What My Toolkit Does

My Personal Mini-Toolkit is a Python program that contains three useful tools:

1. Simple Calculator — performs addition, subtraction, multiplication, and division.
2. To-Do List — lets the user add, remove, and view tasks.
3. Number Checker — checks whether a number is even or odd and whether it is positive, negative, or zero.

The program uses a menu that keeps running until the user chooses Quit.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the program with:

python toolkit.py

4. Choose a number from the menu and follow the instructions.

## Reflection

The hardest part of this project was putting all the tools inside one menu-driven program. The menu loop was challenging because I had to make sure it returned after each tool finished. One bug I had to pay attention to was making sure the program did not crash when the user entered an invalid menu choice. The To-Do List helped me understand how lists can change while a program is running. I also learned how loops and conditionals can work together to make a program interactive. I am proud that all three tools can be accessed from the same menu. With one more week, I would add more tools and improve the design of the program.
